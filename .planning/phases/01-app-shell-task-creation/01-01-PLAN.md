Create `index.html` as a complete, self-contained HTML5 document. Use EXACTLY the DOM structure from TechArch — do not deviate from IDs, element types, or nesting.

**EXACT DOM structure required (from TechArch-TodoApp.md):**

```html
<body>
  <div id="app">
    <header>
      <h1>TodoApp</h1>
    </header>
    <div id="banner" role="alert" aria-live="polite"></div>
    <main>
      <form id="task-form">
        <input id="task-input" type="text" ... />
        <button type="submit">Add</button>
        <span id="validation-msg" aria-live="polite"></span>
      </form>
      <ul id="task-list" aria-label="Task list"></ul>
      <p id="empty-state" hidden>No tasks yet. Add one above!</p>
    </main>
  </div>
</body>
```

**Full document requirements:**

1. `<!DOCTYPE html>` declaration
2. `<html lang="en">`
3. `<head>` containing:
   - `<meta charset="UTF-8">`
   - `<meta name="viewport" content="width=device-width, initial-scale=1.0">`
   - CSP meta tag (EXACT from TechArch security section):
     ```html
     <meta http-equiv="Content-Security-Policy"
           content="default-src 'none'; script-src 'self'; style-src 'self'; img-src 'self';">
     ```
   - `<title>TodoApp</title>`
   - `<link rel="stylesheet" href="styles.css">`
4. `<body>` with exact DOM structure above
5. `<script src="app.js" defer></script>` — place before `</body>`, use `defer`

**task-input attributes** (from FRD accessibility requirements):
- `type="text"`
- `id="task-input"`
- `placeholder="Add a task…"` (Claude's discretion — utilitarian)
- `autocomplete="off"`
- `autofocus` — auto-focus on load per FRD non-functional requirements
- `aria-label="Task name"` or visible label (choose autofocus + placeholder; no separate label required)
- `maxlength="500"` — matches MAX_NAME_LENGTH from TechArch

**Heading text:** Use "TodoApp" as the `<h1>` text (matches TechArch DOM spec exactly).

**No external resources** — no Google Fonts, no CDN links, no external images.

<task type="auto">
  <name>Task 2: Create styles.css with full visual layer</name>
  <files>styles.css</files>
  <action>
Create `styles.css` implementing all visual styling. This is a pure CSS file — no external fonts, no @import from CDNs.

**Locked decisions (from CONTEXT.md — NON-NEGOTIABLE):**
- Minimal/utilitarian aesthetic — white background, black/gray text, no decorative elements
- Narrow centered column — approximately 500–600px wide, centered in viewport
- Black/grayscale only — NO color accents on buttons, focus states, or interactive elements
- System font stack (Claude's discretion: `font-family: -apple-system, BlinkMacSystemFont, "Segoe UI", Roboto, Helvetica, Arial, sans-serif`)

**Required CSS classes (EXACT names from TechArch — do not rename):**

| Class | Purpose |
|-------|---------|
| `.task-item` | Base task list item row |
| `.task-item--completed` | Strikethrough + muted colour for completed tasks |
| `.banner--persistent` | Full-width persistent warning banner |
| `.banner--dismissible` | Auto-dismiss banner variant |
| `.validation-msg--visible` | Shows inline input validation error |

**Implementation requirements:**

1. **Layout:** `#app` is a narrow centered column. Use `max-width: 560px; margin: 0 auto; padding: 1rem;`

2. **Typography:** System font stack. `font-size: 1rem; line-height: 1.5;`

3. **Header `<h1>`:** Simple text, no decorative border/underline. `font-size: 1.5rem; font-weight: 600; margin-bottom: 1rem;`

4. **`#task-form`:** Flex row — input takes remaining space, button fixed width. No decorative box shadow.
   ```css
   #task-form { display: flex; gap: 0.5rem; margin-bottom: 1rem; flex-wrap: wrap; }
   #task-input { flex: 1; min-width: 0; padding: 0.5rem; border: 1px solid #999; font-size: 1rem; }
   #task-form button[type="submit"] { padding: 0.5rem 1rem; background: #000; color: #fff; border: none; cursor: pointer; font-size: 1rem; min-width: 44px; min-height: 44px; }
   ```
   Monochrome only — no colored focus ring. Use `outline: 2px solid #000` on `:focus` states.

5. **`#validation-msg`:** Hidden by default. Show via `.validation-msg--visible`.
   ```css
   #validation-msg { display: none; color: #555; font-size: 0.875rem; width: 100%; }
   #validation-msg.validation-msg--visible { display: block; }
   ```

6. **`#task-list`:** Remove default list styling. `list-style: none; margin: 0; padding: 0;`

7. **`.task-item`:** Flex row — checkbox left, name fills remaining, delete button right. Min touch target 44×44px for checkbox and delete button.
   ```css
   .task-item { display: flex; align-items: center; gap: 0.5rem; padding: 0.5rem 0; border-bottom: 1px solid #eee; min-height: 44px; }
   .task-item input[type="checkbox"] { width: 18px; height: 18px; min-width: 44px; min-height: 44px; cursor: pointer; accent-color: #000; }
   .task-item .task-name { flex: 1; }
   .task-item .task-delete { background: none; border: none; cursor: pointer; color: #666; font-size: 1rem; padding: 0.25rem 0.5rem; min-width: 44px; min-height: 44px; display: flex; align-items: center; justify-content: center; }
   .task-item .task-delete:hover { color: #000; }
   ```

8. **`.task-item--completed`:** Strikethrough + muted color. WCAG AA 3:1 minimum contrast.
   ```css
   .task-item--completed .task-name { text-decoration: line-through; color: #767676; }
   ```
   Note: `#767676` on white background = 4.54:1 contrast ratio (exceeds WCAG AA 3:1 minimum). Do NOT use lighter grays that fail contrast.

9. **`#empty-state`:** Muted, centered.
   ```css
   #empty-state { color: #767676; text-align: center; margin: 2rem 0; font-size: 0.875rem; }
   ```

10. **`#banner`:** Full-width at top of `#app`.
    ```css
    #banner { display: none; padding: 0.75rem 1rem; margin-bottom: 1rem; font-size: 0.875rem; border: 1px solid #000; }
    #banner.banner--persistent { display: block; background: #f5f5f5; }
    #banner.banner--dismissible { display: block; background: #f5f5f5; }
    ```

11. **Responsive:** No horizontal scrollbar at 320px. Input/button stack on narrow viewports.
    ```css
    @media (max-width: 480px) {
      #task-form { flex-direction: column; }
      #task-form button[type="submit"] { width: 100%; }
    }
    ```

12. **`body`:** Remove default margin. `body { margin: 0; padding: 0; background: #fff; color: #000; }`
