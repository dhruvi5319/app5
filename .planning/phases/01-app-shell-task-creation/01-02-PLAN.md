From FRD-TodoApp.md F0 validation rules and TechArch TypeScript interfaces:

**Function signature (EXACT from TechArch):**
```typescript
function validateTaskName(rawName: string): ValidationResult
```

**ValidationResult type (EXACT from TechArch):**
```typescript
interface ValidationResult {
  valid: boolean;
  errorCode?: TaskErrorCode;
  errorMessage?: string;
}
```

**TaskErrorCode values relevant to this function:**
- `"ERR_EMPTY_TASK"` — Submitted blank or whitespace-only input
- `"ERR_TASK_TOO_LONG"` — Input exceeds MAX_NAME_LENGTH (500)

**MAX_NAME_LENGTH constant (EXACT from TechArch):** `500`

**Validation rules (from FRD-TodoApp.md F0):**
1. Trim leading/trailing whitespace from `rawName` before validation
2. If trimmed value is empty string (length === 0) → return `{ valid: false, errorCode: "ERR_EMPTY_TASK", errorMessage: "Task name cannot be empty" }`
3. If trimmed value exceeds 500 characters → return `{ valid: false, errorCode: "ERR_TASK_TOO_LONG", errorMessage: "Task name must be 500 characters or fewer" }`
4. Otherwise → return `{ valid: true }`

| Input | Expected Output |
|-------|----------------|
| `""` | `{ valid: false, errorCode: "ERR_EMPTY_TASK" }` |
| `"   "` | `{ valid: false, errorCode: "ERR_EMPTY_TASK" }` |
| `"\t\n"` | `{ valid: false, errorCode: "ERR_EMPTY_TASK" }` |
| `null` | `{ valid: false, errorCode: "ERR_EMPTY_TASK" }` (treat null as empty) |
| `undefined` | `{ valid: false, errorCode: "ERR_EMPTY_TASK" }` (treat undefined as empty) |
| `"Buy milk"` | `{ valid: true }` |

| `"  " + "x".repeat(499)` | `{ valid: true }` (trim then 499 chars = valid) |
