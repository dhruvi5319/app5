**Section 4 — Task functions:**

`addTask(name)`:
- Call `validateTaskName(name)` → if invalid, call `showValidationMsg(result.errorMessage)` and return `null`
- If valid: call `clearValidationMsg()`
- Create task object: `{ id: generateId(), name: name.trim(), completed: false, createdAt: new Date().toISOString() }`
- `tasks.unshift(newTask)` — prepend to array (newest first)
- Call `saveTasks(tasks)` — stub in Phase 1
- Call `renderTaskList(tasks)`
- Return the new task object

`toggleTask(taskId)`:
- Find task: `const task = tasks.find(t => t.id === taskId)`
- If not found: `console.warn('ERR_TASK_NOT_FOUND', taskId)` and return
- `task.completed = !task.completed`
- Call `saveTasks(tasks)`
- Re-render: call `renderTaskList(tasks)` (full re-render per TechArch state flow diagram)

`deleteTask(taskId)`:
- Check task exists: if not found, `console.warn('ERR_TASK_NOT_FOUND', taskId)` and return
- `tasks = tasks.filter(t => t.id !== taskId)`
- Call `saveTasks(tasks)`
- Call `renderTaskList(tasks)` (handles empty state automatically)

---

**Section 5 — Render functions:**

`renderTaskList(tasks)`:
- Get `#task-list` and `#empty-state` elements
- Clear `#task-list`: `taskList.innerHTML = ''` — safe here (clearing, not inserting user content)
- If `tasks.length === 0`: `emptyState.hidden = false`; return
- `emptyState.hidden = true`
- For each task: `taskList.appendChild(renderTaskItem(task))`

`renderTaskItem(task)`:
- Create `<li class="task-item">` — add `task-item--completed` class if `task.completed === true`
- Set `data-task-id` attribute on the `<li>`: `li.dataset.taskId = task.id`
- Create checkbox: `<input type="checkbox">` — set `checked` if `task.completed`
  - Add `aria-label="Toggle completion"`
- Create task name `<span class="task-name">` — **CRITICAL: use `textContent`, NEVER `innerHTML`**:
  ```javascript
  const nameSpan = document.createElement('span');
  nameSpan.className = 'task-name';
  nameSpan.textContent = task.name;  // XSS PREVENTION: textContent only
  ```
- Create delete button: `<button class="task-delete" type="button">` with `aria-label="Delete task: " + task.name`
  - Button text: `"×"` (the × character) or `"Delete"` (use `textContent`)
  - **CRITICAL: use `textContent` for button label too, never `innerHTML`**
- Append checkbox, nameSpan, deleteBtn to `<li>`
- Return the `<li>`

`showBanner(options)`:
- Get `#banner` element
- Set `textContent` to `options.message`  ← textContent, not innerHTML
- Remove existing `banner--persistent` and `banner--dismissible` classes
- Add `banner--${options.variant}` class
- If `options.variant === 'dismissible'`: set `setTimeout(clearBanner, options.dismissAfterMs ?? 5000)`

`clearBanner()`:
- Get `#banner`, set `textContent = ''`, remove `banner--persistent` and `banner--dismissible` classes

`showValidationMsg(message)`:
- Get `#validation-msg`, set `textContent = message` (NOT innerHTML), add class `validation-msg--visible`

`clearValidationMsg()`:
- Get `#validation-msg`, set `textContent = ''`, remove class `validation-msg--visible`

---

**Section 6 — Event handlers:**

`handleFormSubmit(event)`:
- `event.preventDefault()`
- Get `#task-input` value
- Call `addTask(input.value)` — addTask handles validation internally
- If `addTask` returns a Task (not null): clear the input (`input.value = ''`), return focus to input (`input.focus()`)
- If `addTask` returns null: do NOT clear input (validation failed; user sees error)

`handleTaskListClick(event)`:
- Use event delegation on `#task-list`
- Find nearest `[data-task-id]` ancestor: `const li = event.target.closest('[data-task-id]')`
- If no `li` found: return (click outside task items)
- Get `taskId = li.dataset.taskId`
- If `event.target` is a checkbox (`event.target.type === 'checkbox'`): call `toggleTask(taskId)`
- If `event.target` matches `.task-delete` (or is the delete button): call `deleteTask(taskId)`
